| Long headings | `chunk_document` raises `ValueError` when the title plus a heading leave no room under the 400-token cap; it does not truncate | Eo's decision 2026-10-19: a clear error beats silently cutting text | A save with a very long heading fails with a readable message; callers must show it (FR2 style) |
| Page download | We download with `httpx` (async client, plus a sync wrapper `fetch_html` around `asyncio.run`, Python 3.12) and give trafilatura only the HTML string (`trafilatura.extract`). We do not use trafilatura's own downloader. `fetch_html` must not be called from inside a running event loop (it raises a readable error) | trafilatura's timeout is per step (a 2 s setting took 8 s), every failure is the same `None` so no readable cause is possible, it retries WITHOUT certificate checks by default (`INSECURE_SSL_FALLBACK` on), and the content type is known only after the whole body is downloaded (V33, V34). Decided by Eo 2026-10-20 (U20) | `httpx` is declared in `pyproject.toml` (it was only transitive); certificate checks stay on, with no unverified fallback. Private-address block, redirect cap of 5, 5 MB cap and content-type check are Day 5 (U21) |
| Download timeout | The 15-second timeout is a TOTAL wall-clock limit for the whole download, enforced by our code with `asyncio.timeout`; httpx's own per-step timeouts are off | FR2 says "15-second timeout"; a per-step limit can add up to far more (V34) | Tested with `httpx.MockTransport`: a stall of 5 s with a 0.2 s limit ended in about 0.2 s (V39) |
| URL normalization | PRD rules only (FR7): lowercase scheme and host, no fragment, no `utm_*`, `fbclid` or `gclid` parameters (names compared ignoring case), no trailing slash on the path (so `http://x.com/` and `http://x.com` are one). Kept as given: path case, parameter order, `www.`, `http` versus `https`, ports. **Not normalized yet:** parameter order, default ports and `http`/`https`, other tracking parameters (`ref`, `mc_cid`, `igshid`), `www.`, percent-encoding case and non-ASCII hosts, `user:password@`, path case, repeated slashes and `index.html`, percent-encoded parameter names, `#!` routes (dropped as fragments). Only ONE trailing slash is removed | Eo's decision 2026-10-20 (U22): do exactly what the PRD says and no more | Two URLs that differ in any listed case get two identity keys and save twice. Each case is pinned in `tests/test_urls.py` so a later change is deliberate |
| Page text rules | A page is rejected if `trafilatura.extract` returns `None`, if it has under 200 characters (whitespace collapsed to single spaces), or under 3 sentences. **Assumed rule (FR2 gives none):** a sentence is a piece cut at `.`, `!` or `?` followed by whitespace, or at a line break, but not after `e.g.`, `i.e.`, `vs.`, `Mr.`, `Mrs.`, `Ms.`, `Dr.`, `Prof.`, `Fig.`, `approx.` or dotted initials such as `U.S.`; a piece of fewer than 3 words is joined to the previous one | `extract` alone is not enough: a menu-only page returned `"A\nB"` and a one-line page returned its line (V32). Decided by Eo 2026-10-20 (U23) | Headings of 3 or more words count as sentences, and a menu of any length counts at most once (V40). Only made-up fixtures were tried; real pages: Day 5 |
| Redirects | A 3xx answer is refused with "The page redirects; redirects are not supported yet." until Day 5 (`follow_redirects=False`) | Following a redirect needs the private-address re-check on every hop (FR2), which is Day 5. Many real pages redirect (for example `http` to `https`), so they fail until then. Eo agreed 2026-10-20 | Day 5 (U21) |
| URL fields on a web document | `documents.source_url` = the link exactly as given (spaces trimmed); `normalized_url` = the normalized form; `identity_key` and `source_label` = the normalized form; `source_type` = `web`; `content_hash` = SHA-256 of the extracted text, not of the HTML. Title: `--title`, else the page's own title, else the normalized URL. No URL is stored on `chunks`. The page is downloaded from the link as given, not the normalized form | PRD FR7: the identity key of a web page is its normalized URL; the columns already exist in `0001_init.sql`, so no migration was needed | Same plain "Already saved" error as text and Markdown on a repeat; supersede and `--replace` are block g |
